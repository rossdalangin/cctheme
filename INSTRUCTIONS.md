# CloseClient Elite Authority Theme

The premium WordPress authority system for high-ticket coaches and consultants.

## Getting Started

1. **Activate the Theme**: Once activated, you will see the default branding and layout.
2. **Theme Utilities**: Go to **Appearance > Customize > 5. Theme Setup & Tools**.
   - Click **Generate Now** under "Recreate Starter Pages" to automatically build your core Sales, Home, and About pages.
   - This will also set your "Home" page as the static front page.
3. **Customize Content**: Use the WordPress Customizer (**Appearance > Customize**) to edit all headlines, images, colors, and typography.

## Key Features

- **100% Dynamic**: Every visible string can be edited in the Customizer.
- **Conversion-Locked**: Designed with direct-response principles from Hormozi and Brunson.
- **Bento Grids**: Modern, organized data visualization for services and stats.
- **Action Hooks**: Developers can extend the theme using hooks like `closeclient_before_header` and `closeclient_after_footer`.
- **Shortcodes**: Use sections anywhere:
  - `[closeclient_hero]`
  - `[closeclient_services]`
  - `[closeclient_pricing]`
  - ...and all other 14 sections.

## Page Templates

- **Sales Page**: Optimized for long-form high-ticket offers.
- **Lead Magnet**: Built for high-conversion list building.
- **Authority About**: Specifically designed to build coach expert positioning.
